01 // The 3-Lane Architecture Overview

PRIVACY68 v1.3.0 is built on a high-throughput, privacy-first 3-Lane Command Router. Every voice command is analyzed locally in real time and directed to the optimal execution path based on complexity, required reasoning depth, and latency tolerance:

+-----------------------------------------------------------------------------------+ | PRIVACY68 3-LANE DECISION ENGINE | +-----------------------------------------------------------------------------------+ | [Microphone Input 16kHz] ---> [Silero Neural VAD] ---> [faster-whisper STT] | | | | [Voice Authorization OK] <--- [ECAPA-TDNN 512-d Speaker Verification] | | │ | | ┌─────────────────┴─────────────────┐ | | ▼ ▼ | | [Deterministic Matcher] [Intent Classifier ML] | | │ │ | | ┌──────────┴───────────┬───────────────────────┴──────────┐ | | ▼ ▼ ▼ | | [LANE 1: FAST LANE] [LANE 2: API LANE] [LANE 3: LOCAL LLM] | | Latency: < 2.0ms Latency: 300ms - 1.2s Latency: 100ms - 400ms | | AI Overhead: 0% OpenAI / Groq Cloud Ollama Qwen2.5 Local | | Deterministic Win32 Coding & Complex Reasoning 100% Air-Gapped Fallback | +-----------------------------------------------------------------------------------+

This tri-tiered structure guarantees that routine desktop controls (volume, app launching, window management) execute with near-zero latency, while open-ended research questions and coding workflows leverage advanced reasoning engines.

02 // Speech & VAD Pipeline Upgrades

Continuous audio capture operates via a high-performance 16kHz circular buffer managed by sounddevice and filtered in real time by Silero Neural VAD:

  • Phonetic Wake Word Expansion: The engine automatically matches phonetic variations including "Privacy 68", "Privacy sixty eight", "Privacy sixty-eight", "Privacy six eight", and digit-separated aliases.
  • 2-Gram Multi-Word Fuzzy Matching: Applies sliding Levenshtein distance across 2-word sequences, accommodating fast speech, regional pronunciation, and low-fidelity headsets.
  • Dynamic Peak Normalization: Every audio frame is normalized against its peak amplitude before transcription, ensuring quiet voices trigger as reliably as studio microphones.
  • Silero VAD Gating: 80ms audio frames are analyzed by the Silero neural network. Non-speech background noise is rejected, dropping CPU idle usage to under 1.5%.
  • Whisper Decoder Priming: Decoder token probabilities are primed with domain hotwords via config.INITIAL_PROMPT to prevent dropping numerical identifiers.

03 // Microphone Setup & Audio Diagnostics

Proper microphone levels ensure 100% accurate wake word recognition. Follow these diagnostic steps:

1. Windows Privacy Permissions

Ensure Windows allows desktop apps access to the microphone: Navigate to Settings → Privacy & Security → Microphone. Toggle "Allow desktop apps to access your microphone" to ON.

2. Audio Level Benchmark

Test your microphone's live input sensitivity and background noise floor by running this test command in PowerShell:

python -c "import sounddevice as sd, numpy as np; d=sd.rec(int(16000*3), 16000, 1, 'float32'); sd.wait(); print('Peak:', round(float(np.max(np.abs(d))), 4), 'RMS:', round(float(np.sqrt(np.mean(d**2))), 4))"
ACOUSTIC STATE ACCEPTABLE RMS ACCEPTABLE PEAK RECOMMENDED ACTION
Room Silence < 0.005 < 0.015 Optimal noise floor. VAD will remain in low-power idle scan.
Normal Speech > 0.020 > 0.080 Ideal speech level. Whisper transcribes with 99%+ accuracy.
Low Sensitivity < 0.010 < 0.030 Increase microphone volume to 85% in Windows Sound Control Panel.

04 // Biometric Voice Authentication (Voice Lock)

PRIVACY68 features biometric speaker authorization powered by ECAPA-TDNN / CAM++ neural embeddings (512-dimensional vector space). When activated, commands are only executed if vocal tract biometrics match the enrolled master profile.

Enrollment Procedure

  1. Open the PRIVACY68 Control Center (Right-click system tray icon → Open Dashboard).
  2. Navigate to the Voice Profile / Biometrics tab.
  3. Click "Enroll Master Voice" and recite the 3 calibration phrases clearly.
  4. The model extracts normalized 512-d acoustic embeddings, averages the vector cluster, and stores it in %APPDATA%/PRIVACY68/voice_lock/.

Threshold Tuning

THRESHOLD SECURITY PROFILE BEHAVIOR & ENVIRONMENT
0.40 – 0.45 Relaxed Accommodates head colds, background music, or varying distances from mic.
0.50 (Default) Balanced Rejects unfamiliar speakers while reliably recognizing the owner.
0.65 – 0.75 Strict Biometric High security mode. Rejects slight vocal variations and voice recordings.

Note: Adjusting the threshold in the dashboard takes effect dynamically in memory with zero app restarts.

06 // Plugin Architecture & Mobile Web Remote

Extend PRIVACY68 with custom desktop automations by inheriting from BasePlugin. Dropping scripts into %APPDATA%/PRIVACY68/plugins/ automatically registers new voice intents with hot-reloading:

from plugins.base_plugin import BasePlugin class MediaControlPlugin(BasePlugin): name = "Custom Media Controller" version = "1.0.0" def register_intents(self) -> dict: return {"media.next": self.next_track} def get_intent_phrases(self) -> dict: return {"media.next": ["next song", "skip track", "play next"]}

Mobile Web Remote (Local Wi-Fi)

Control your computer from your smartphone or tablet! PRIVACY68 hosts an authenticated local server on port 8765. Open Dashboard → Remote Server, scan the displayed QR code with your phone camera, and execute voice or text commands across your local network.

08 // Configuration Reference (`config.py`)

Core thresholds, model selections, and device parameters can be fine-tuned in config.py:

# config.py settings reference # Audio Stream Settings (16kHz, 1280 samples = 80ms chunks) SAMPLE_RATE = 16000 BLOCK_SIZE = 1280 CHANNELS = 1 DTYPE = "float32" # Silence / Voice Activity Detection (Silero VAD) VAD_THRESHOLD = 0.50 # Speech probability threshold (0.0 to 1.0) VAD_IDLE_THRESHOLD = 0.30 # Lower threshold for wake-word scan gating SILENCE_DURATION_CHUNKS = 8 # 8 chunks * 80ms = 0.64s pause for speech cutoff SILENCE_THRESHOLD = 0.008 # Fallback RMS noise floor gate # Whisper Model Configuration WHISPER_MODEL_SIZE = "medium.en" # "small.en", "medium.en" WHISPER_DEVICE = "cuda" if _HAS_CUDA else "cpu" WHISPER_COMPUTE_TYPE = "float16" if _HAS_CUDA else "int8" WHISPER_BEAM_SIZE = 8 # Wider beam = maximum command accuracy # Initial Prompt for Whisper Priming INITIAL_PROMPT = ( "Privacy 68, Privacy68, open chrome, launch vs code, mute volume, " "take screenshot, lock screen, open youtube, next track, play music." )
