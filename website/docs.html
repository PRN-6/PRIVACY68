01 // Architecture Overview

PRIVACY68 is a zero-latency, 100% offline autonomous voice assistant engineered specifically for Windows desktops. Unlike cloud-dependent voice interfaces, PRIVACY68 executes speech-to-text, neural speaker authorization, intent classification, and system automation entirely on local hardware (Nvidia CUDA float16 or CPU int8 fallback).

+-----------------------------------------------------------------------------------+ | PRIVACY68 SPEECH PIPELINE | +-----------------------------------------------------------------------------------+ | [Microphone Input 16kHz] --> [Silero VAD (ONNX)] --> [faster-whisper STT] | | | | | [Voice Authorized OK] <-- [CAM++ Speaker Verification (512-d)] <+ | | | | | [Semantic Router]===> (Conf >= 0.78) ==> [Fast-Lane Plugin Execution (<2ms)] | |===> (Conf < 0.78)==> [Ollama Qwen 2.5 Local AI Fallback] | +-----------------------------------------------------------------------------------+

02 // Speech & VAD Pipeline

Audio capture utilizes a continuous 16kHz mono circular buffer streaming through Silero VAD (ONNX runtime). Non-speech acoustic frames are filtered out prior to triggering faster-whisper inference, reducing CPU usage to under 1.5% during background standby.

  • VAD Engine: Silero VAD (ONNX) with 32ms frame chunk processing.
  • Speech Recognition: CTranslate2 faster-whisper-medium.en loaded directly into CUDA GPU memory.
  • Wake Word Detector: Custom keyword regex scan ("Alexa" or custom keyword configured in config.py).
  • Auto-Correction: Natural language filter strips filler words (hmmm, ummm, stutters) prior to router classification.

03 // Dual-Lane Router

The Semantic Router matches incoming transcribed speech against indexed training phrases across active skills & plugins using TF-IDF vector embeddings:

ROUTER LANE LATENCY TRIGGER CRITERIA TARGET EXECUTOR
FAST-LANE < 2.0 ms Cosine Similarity Score >= 0.78 Direct Python Plugin Method Execution
OLLAMA AI ~120.0 ms Cosine Similarity Score < 0.78 (Complex Intent) Local LLM (Qwen2.5) Tool Selection & Parameter Extraction

04 // CAM++ Voice Authentication

PRIVACY68 features an optional neural Voice Lock powered by ModelScope's CAM++ speaker embedding model (512-dimensional vector space). Voice commands are only executed if cosine similarity against your enrolled master voice profile meets the similarity threshold (default: 0.50).

05 // Plugin Architecture

Plugins inherit from BasePlugin and register intent phrases with action callbacks. Dropping any Python script into %APPDATA%/PRIVACY68/plugins/ automatically re-indexes the Semantic Router without restarting the assistant.

# Sample PRIVACY68 Plugin structure from plugins.base_plugin import BasePlugin class CustomPlugin(BasePlugin): name = "Custom Automation" icon = "⚡" def register_intents(self) -> dict: return { "custom.action": self.execute_action } def get_intent_phrases(self) -> dict: return { "custom.action": ["run custom macro", "trigger automation"] }

07 // Configuration Reference

Modify config.py in the project root to customize hardware device targeting, wake words, and neural parameters:

# config.py settings snippet WHISPER_MODEL_NAME = "medium.en" # whisper model size (tiny, base, small, medium, large-v3) WHISPER_DEVICE = "cuda" # "cuda" or "cpu" VAD_THRESHOLD = 0.50 # Silero VAD confidence threshold WAKE_WORD = "Alexa" # Wake word phrase FAST_LANE_THRESHOLD = 0.78 # Semantic Router similarity cutoff OLLAMA_MODEL = "qwen2.5:latest" # Local AI LLM model name
