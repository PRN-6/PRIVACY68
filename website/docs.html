01 // Three-Lane Command Execution Architecture

PRIVACY68 v1.7.4 routes every user request through a high-efficiency Three-Lane Execution Architecture (actions/executor.py). This tri-lane pipeline guarantees instant sub-millisecond execution for deterministic OS operations, zero-token replay for previously synthesized tasks, and robust multi-cloud LLM reasoning with automatic self-healing for complex compound workflows.

Local Quick Command Bar (Ctrl+Alt+Space) / Telegram Remote Gateway (RAM Audio) | v Action Executor (actions/executor.py - Three-Lane Command Router): +---------------------------------------------------------------------------------+ | [LANE 1] Built-in Native Win32 Fast-Paths (< 5ms Latency, Zero LLM Token Cost) | | - Volume Master Controls: mute, unmute, set volume 0-100 | | - Virtual Desktops: switch to desktop 1-10, next/prev desktop, task view | | - Window Operations: minimize, maximize, restore, close active window | | - Native App Launchers: Chrome, Brave, WhatsApp Web, Gmail, VS Code | | - Media Keys: play/pause, next track, prev track, stop | +---------------------------------------------------------------------------------+ | (if not matched by native Win32 pattern) v +---------------------------------------------------------------------------------+ | [LANE 2] Learned Skills Instant Replay (0ms Synthesis Latency, 100% Deterministic)| | - Dynamically auto-crystallized from successful Lane 3 executions | | - Stored in %APPDATA%\PRIVACY68\learned_skills.json | | - Bypasses LLM API calls entirely for recurring commands | +---------------------------------------------------------------------------------+ | (if no cached skill matches) v +---------------------------------------------------------------------------------+ | [LANE 3] Cascading Multi-Cloud AI Agent Brain (Self-Healing Reflection Loop) | | - Injects 11 OpenClaw Markdown Skills (skills/*/SKILL.md) into system prompt | | - Cascading Failover: Gemini 3.1 Flash-Lite -> Groq LPU -> Claude -> GPT-4o | | - 3-Tier AST Security Guard: Safe / Sensitive / Critical Confirmation Window | | - Isolated Subprocess Execution with 2-Attempt Reflection & Code Correction | +---------------------------------------------------------------------------------+

Zero-LLM fast paths execute locally in under 5ms with zero token cost. When code generation is required, Lane 3 synthesizes sandboxed Python automation, validates it against the AST security policy, and auto-crystallizes verified solutions into Lane 2 for future zero-cost replay.

Cascading Multi-Cloud AI Failover Topology

To ensure high availability and prevent single-provider outage failures:
• Primary: Google Gemini 3.1 Flash-Lite (gemini/gemini-3.1-flash-lite) — sub-300ms reasoning, zero local GPU usage.
• Failover 1: Groq Cloud LPU (groq/llama-3.3-70b-versatile) — instant fallback on HTTP 429 rate limits or cloud timeouts.
• Failover 2 & 3: Anthropic Claude 3.5 Sonnet / OpenAI GPT-4o-mini via LiteLLM gateway.
• Offline Fallback: Local Ollama (http://127.0.0.1:11434) or LM Studio for 100% air-gapped workstations.

02 // Strict Zero-Mic Hardware Policy & Acoustic Pipeline

Traditional assistants maintain background audio listeners to detect wake words (*"Hey Siri"*, *"Alexa"*), creating security vulnerabilities and room eavesdropping risks. PRIVACY68 enforces a strict Zero-Mic Hardware Isolation Model:

  • Zero Local Mic Eavesdropping: The workstation PC microphone is completely disabled. No background audio daemons, polling loops, or ambient recordings exist on the workstation.
  • Out-of-Band Voice Processing: Voice commands are received exclusively via encrypted Telegram voice notes. Audio bytes are decoded directly in RAM using PyAV, with zero temporary audio files written to disk.
  • Dynamic Peak Normalization: Every in-memory audio chunk is dynamically scaled using peak amplitude scaling:
    norm = (audio / peak) × 0.9
    Maximizes dynamic range and acoustic clarity for soft-spoken voice notes without signal clipping.
  • Dual Speech Transcription Engine: Uses Google Web Speech ASR for instant cloud transcription with automatic local Faster-Whisper int8 CPU fallback if internet access is interrupted.
  • Quick Command Bar (Ctrl+Alt+Space): For hands-on PC interaction, users trigger the transparent HUD command bar to type natural-language instructions with zero audio capture.

03 // Telegram Remote Gateway & Teleoperation Guide

The Telegram Remote Gateway (channels/telegram.py) allows you to control your Windows PC remotely from your smartphone over 4G/5G mobile networks from anywhere in the world.

1. Ephemeral 6-Character PIN Pairing

To prevent unauthorized access, pairing uses a dynamic 6-character PIN generated securely on your workstation:

  1. Launch PRIVACY68 and click the Telegram card in the Control Center Dashboard.
  2. Copy the generated 6-character pairing PIN (e.g., PR68A1).
  3. Open your Telegram bot on your smartphone and send: /pair PR68A1.
  4. The bot confirms pairing and binds your Telegram Chat ID into Windows Credential Manager. All subsequent commands from unknown chat IDs are rejected immediately.

2. Supported Remote Telegram Commands

04 // 3-Tier Security Guard & Confirmation Policy

PRIVACY68 protects system integrity using an AST-based 3-Tier Security Execution Model. Any Python script synthesized by the Agent Brain is analyzed via Abstract Syntax Tree (AST) inspection before execution, ensuring destructive or critical actions are gated behind user confirmation.

TIER RISK LEVEL EXAMPLE OPERATIONS EXECUTION POLICY
Tier 1 SAFE (Instant) App launch, media controls, volume adjustments, virtual desktops, web searches, window controls Executed immediately with zero prompt latency.
Tier 2 SENSITIVE (Audited) File creation/modification, closing apps, clipboard writes, network ping checks Executed with visual HUD notification and audit trail log.
Tier 3 CRITICAL (Confirmation Gated) File/folder deletion, Git push, terminating processes, disk formatting, registry edits Halted. Prompts user with 15s timeout window. Requires explicit "yes" or "proceed".

Self-Correction Reflection Loop

If a synthesized script encounters an exception during execution, the runner captures the standard error traceback and feeds it back into the Agent Brain reflection prompt. The LLM diagnoses the fault (e.g. correcting a file path, missing import, or Windows API parameter) and generates corrected code automatically (up to 2 retry attempts).

06 // OpenClaw Skills Architecture & Native Services

PRIVACY68 implements the open OpenClaw Markdown Skills Standard. Skills are declarative Markdown files (SKILL.md) stored under skills/<skill_name>/SKILL.md or in %APPDATA%\PRIVACY68\skills\. The Skill Registry dynamically matches prompt keywords and injects exact CLI syntax and recipes into the Agent Brain system prompt.

Core OpenClaw Skills:
• antigravity: IDE workspace navigation, tool invocation, and project debugging.
• docker: Container lifecycle management, image inspection, and compose stack control.
• git: Repository status, branch switching, commits, and diff inspection.
• github: GitHub CLI pull requests, issues, check runs, and Windows Credential Manager authentication.
• browser: Chrome, Brave, and Edge multi-profile automation and web search queries.
• vscode: Visual Studio Code workspace opening and extension control.
• whatsapp: Pre-populated WhatsApp Web messaging and contacts.

Native Background Services:
• channels/telegram.py: Global out-of-band mobile teleoperation on 4G/5G networks.
• services/gmail.py: Direct multi-account browser compose and inbox routing via Google's authuser gateway.
• services/system.py: Hardware volume, virtual desktops (1-10, next, prev, task view), display lock, and process management.
