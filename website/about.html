About PRIVACY68 Voice Assistant

Building an uncompromised, hyper-fast, private desktop intelligence engine.

// THE PRIVACY-FIRST PHILOSOPHY

Modern voice assistants send every spoken word, audio snippet, and ambient recording to remote cloud telemetry servers. PRIVACY68 was born out of a radical commitment to personal privacy: your voice data belongs on your device, nowhere else.

By combining CTranslate2-accelerated Whisper models, ONNX Silero Voice Activity Detection, CAM++ 512-d neural speaker verification, and local Ollama LLM execution, PRIVACY68 delivers sub-50ms voice assistant capabilities without opening a single network socket to third-party clouds.

Technology Stack & Libraries

SPEECH-TO-TEXT

faster-whisper (CTranslate2)

CTranslate2 PyTorch execution engine running Whisper Medium.en on CUDA float16 GPU memory.

VOICE ACTIVITY

Silero VAD (ONNX Runtime)

Ultra-lightweight 32ms frame chunk VAD filter that rejects ambient noise and keyboard clicks.

VOICE SECURITY

CAM++ Speaker Embedder

512-dimensional neural speaker embedding model verifying voice lock cosine similarity (0.50 threshold).

LOCAL REASONING

Ollama AI Core (Qwen 2.5)

Fallback local LLM for intent extraction and complex task planning when fast-lane similarity is under 0.78.

VISION CONTROL

MediaPipe + OpenCV

Webcam hand gesture engine detecting open palm wake, fist mute, slide navigation, and Alt-Tab app switching.

DASHBOARD UI

WebView2 + Tailwind CSS

Modern glassmorphic Tailwind Control Center Dashboard running natively inside pywebview.
