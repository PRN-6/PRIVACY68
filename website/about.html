About PRIVACY68 Voice Assistant

Building an uncompromised, hyper-fast, private desktop intelligence engine.

// THE PRIVACY-FIRST PHILOSOPHY

PRIVACY68 includes local speech-processing components, but the current Agent Brain uses the model identifier ollama/gemma4:31b-cloud. Model requests may be processed by a remote provider; do not assume prompts or command text remain on-device.

The command executor handles a small number of direct cases, such as greetings and pending security confirmations. Most other requests go to the Agent Brain, which asks LiteLLM for Python code and executes it in a subprocess with the application's user permissions.

Technology Stack & Libraries

SPEECH-TO-TEXT

faster-whisper (CTranslate2)

CTranslate2 PyTorch execution engine running Whisper Medium.en on CUDA float16 GPU memory.

VOICE ACTIVITY

Silero VAD (ONNX Runtime)

Ultra-lightweight 32ms frame chunk VAD filter that rejects ambient noise and keyboard clicks.

VOICE SECURITY

CAM++ Speaker Embedder

512-dimensional neural speaker embedding model verifying voice lock cosine similarity (0.50 threshold).

AGENT BRAIN

LiteLLM · gemma4:31b-cloud

Requests generated Python through LiteLLM, then runs returned scripts locally in a subprocess. The configured model identifier is cloud-tagged.

DASHBOARD UI

WebView2 + Tailwind CSS

Modern glassmorphic Tailwind Control Center Dashboard running natively inside pywebview.
