The OpenClaw Markdown Architecture

PRIVACY68 has migrated away from legacy Python plugin classes to OpenClaw Markdown Skills (SKILL.md). Instead of rigid inheritance, tool knowledge is stored in structured Markdown files with YAML frontmatter containing metadata, keywords, CLI syntax, and examples.

When you speak or type a developer command, the Skill Registry matches prompt keywords against active skills and injects exact CLI recipes directly into the Agent Brain prompt. The model writes standard, idiomatic code that runs in an isolated subprocess.

To create a custom skill, simply drop a new folder containing a SKILL.md into %APPDATA%\PRIVACY68\skills\<skill_name>\SKILL.md. PRIVACY68 will index it automatically on the next command.

Sensitive credentials (such as GitHub PAT tokens and Telegram bot keys) are encrypted natively using the Windows Credential Manager vault, ensuring secure persistent storage without plain-text configuration files.
