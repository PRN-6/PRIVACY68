Manage extensions in the desktop dashboard

Open the PRIVACY68 Control Center and choose Plugins to see the plugins registered on this device. From there you can enable or disable entries, create a starter template, install a Python file, or uninstall a user plugin. Built-in plugins cannot be uninstalled.

External Python plugins are discovered from %APPDATA%\PRIVACY68\plugins\. The dashboard can install a .py file into this directory. The plugin manager imports Python code when it loads, so only install code you trust; plugin code runs with the current user's permissions.

The registry is an extension-management interface, not a security boundary. Enabling or disabling a registry entry does not sandbox generated scripts or guarantee that the assistant routes every request through a plugin.
